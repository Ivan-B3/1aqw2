
Данный проект представляет собой мобильное приложение «Заметки», разработанное на фреймворке Flutter с использованием языка Dart и демонстрирующее применение архитектурного подхода Feature-First с элементами Clean Architecture. Приложение реализует полный цикл CRUD-операций, включая создание, чтение, обновление и удаление записей, что полностью соответствует критериям на высшую оценку. В базовой функциональности реализованы поле ввода текста, кнопка сохранения и отображение списка добавленных заметок, а в расширенной версии добавлены возможности редактирования существующих записей через диалоговое окно и их удаления с помощью иконок действий. Структура проекта четко разделена на логические слои: папка data содержит файл notes_repository.dart для работы с данными, domain включает notes_cubit.dart для управления состоянием через паттерн Cubit из библиотеки flutter_bloc, а presentation представлен файлом notes_page.dart, отвечающим за пользовательский интерфейс, при этом точка входа в приложение и настройка зависимостей находятся в main.dart. Использование современных практик разработки делает код чистым, поддерживаемым и легко масштабируемым для дальнейшего добавления новых функций, таких как сохранение в локальную базу данных, категоризация или поиск по тексту.
